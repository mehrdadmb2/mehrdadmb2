**Data notes:** the profile refresh workflow checks the published feeds every 10 minutes. ArzPulse itself updates its market snapshot on its own schedule; PySmartHome publishes the latest telemetry snapshot. GitHub scheduled jobs can be delayed, so the graphic includes source timestamps and freshness states. A stale or unavailable source is labelled as such instead of being presented as current data. Gold and USDT values are displayed in toman; the source stores those values in rial.

**Open the source dashboards:** [ArzPulse market terminal](https://mehrdadmb2.github.io/ArzPulse/) · [PySmartHome control center](https://mehrdadmb2.github.io/PySmartHome-PC/) · [IMDb Showcase](https://mehrdadmb2.github.io/imdb-showcase/)
