# Changelog

## 2.0.0 — Profile redesign and cross-project data

- Rebuilt the profile README with a clearer visual hierarchy, responsive project cards, compact navigation and more useful project descriptions.
- Added a new MB2 vector identity, dark glassmorphism banner, status strip, technology panel, project marks and footer.
- Added a generated market + IoT dashboard using the public ArzPulse and PySmartHome-PC JSON snapshots.
- Converted Rial-denominated gold and USDT prices to Toman for display and added source timestamps/freshness states.
- Added a scheduled IMDb Showcase poster shelf based on personal ratings and locally cached posters.
- Added dedicated scheduled workflows, generator tests, SVG/reference health checks and a PowerShell refresh helper with backups.
- Kept existing Metrics, contribution snake, blog feed, QR assets, contact and support sections.
- Documented that GitHub Actions schedules are best-effort and do not guarantee real-time delivery.
